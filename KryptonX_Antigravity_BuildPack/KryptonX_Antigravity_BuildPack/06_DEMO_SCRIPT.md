# KRYPTONX — 3 TO 4 MINUTE PROTOTYPE VIDEO SCRIPT

## 0:00–0:20 — Hook

“NASA FIRMS can tell us where thermal anomalies were observed. But a hotspot alone does not tell an analyst whether it is an industrial fire, a flare, agricultural burning, or another persistent thermal source.

KryptonX adds the intelligence layer between detection and investigation.”

## 0:20–0:50 — Dashboard

Show Mission Control.

Say:
“KryptonX ingests thermal observations and converts nearby observations into meaningful spatiotemporal events.”

Point to:
- observation count
- thermal events
- industrial candidates
- high/critical events

## 0:50–1:30 — Map + filtering

Filter to High/Critical.

Say:
“Instead of making an analyst inspect every hotspot, KryptonX prioritizes events using thermal severity, persistence, contextual relevance and abnormality.”

Click EVT-1048.

## 1:30–2:20 — Investigation view

Show:
- probable source
- confidence
- evidence
- facility distance
- land cover
- timeline

Say:
“This event is classified as an Industrial Fire Candidate. The system does not claim certainty. It provides a confidence score and the evidence behind the classification.”

Then:
“The event is 3.7 times above its historical baseline and its FRP is increasing across recent observations.”

Show FRP chart.

## 2:20–2:55 — Explainability

Say:
“This is the key difference between detection and intelligence. KryptonX explains why an event was flagged instead of producing an unexplained label.”

Show evidence chips.

## 2:55–3:25 — Compare normal vs abnormal

Open EVT-0921.

Say:
“Now compare this with a persistent industrial thermal source. Its thermal behavior is close to its historical baseline, so the system does not treat persistence alone as a fire.”

This demonstrates the baseline concept.

## 3:25–3:50 — Closing

Return to dashboard.

Say:
“KryptonX combines thermal observations, geospatial context, historical behavior and AI-assisted classification into an investigation-ready event.”

Final line:
“We don't turn heat into certainty. We turn satellite observations into explainable investigation leads.”

## Important recording rule

If using synthetic demo data, keep the DEMO DATA indicator visible and say once:
“For this prototype demonstration, these event values are synthetic; the same pipeline can switch to live FIRMS data through the configured API adapter.”

Do not call synthetic values “live NASA observations.”
